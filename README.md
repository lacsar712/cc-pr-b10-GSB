# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

顶栏可切到「色差轨迹」专页：按时间列出最近若干已出结论的青品偏差点并标套准或套不准；可再选一条已出结论作为对照点，由服务端返回各轨迹点与对照点的青品差额（轨迹数据与差额都由服务端返回，页面不拿总表自己拼）。印刷员可签发轨迹快照，冻结签发当时的点集、对照点与差额；签发后再入库的判定只影响在线轨迹页，历史快照仍停在签发时那一版点集。两种账号都能看轨迹与快照，只有印刷员能签发。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可签发轨迹快照 |
| checker | check123456 | 只看 |

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/trajectory?limit=&baseline_id= | 最近 N 条已出结论的轨迹点；带 baseline_id 时返回对照点与各点青品差额 |
| POST | /api/trajectory/snapshots | 签发快照，冻结当前点集与对照差额（仅印刷员） |
| GET | /api/trajectory/snapshots | 已签发快照列表 |
| GET | /api/trajectory/snapshots/{id} | 单条快照的冻结点集 |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮，也没有签发快照按钮。
4. 多投几笔后，顶栏进入「色差轨迹」，按时间看见这些点，结论与总表一致；切换条数选择可改变列出的点数。
5. 在对照选择里挑一条已出结论的印张，差额区出现各轨迹点与它的青品差额。
6. printer 签发快照后再投新笔，等结论出来：在线轨迹页出现新点，打开已签发快照，点集仍是签发时那一版。
