# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

顶栏可切到「色差轨迹」专页：按时间列出最近若干条已出结论的青品偏差点并标套准或套不准，条数可选 10 / 20 / 50。选一条已出结论作对照点后，服务端返回对照点与各轨迹点的青品差额——轨迹与差额一律由服务端接口给出，前端不拿总表自拼。印刷员可签发轨迹快照，把签发当时的点集与对照差额整体冻结入库；签发后再入库的判定只影响在线轨迹页，历史快照仍停在签发时那一版点集。两个账号都能看轨迹与快照，只有印刷员能签发。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可签发轨迹快照 |
| checker | check123456 | 只看（含轨迹与快照） |

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/trajectory?limit=10\|20\|50 | 最近若干已出结论点，按时间正序 |
| GET | /api/trajectory/delta?reference_id=&limit= | 对照点与各轨迹点的青品差额 |
| POST | /api/trajectory/snapshots | 签发快照，冻结当时点集与差额（仅 printer） |
| GET | /api/trajectory/snapshots | 已签发快照列表 |
| GET | /api/trajectory/snapshots/{id} | 快照冻结版全文 |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. 多投几笔后打开顶栏「色差轨迹」，轨迹页按时间看到这些点，结论与总表一致。
5. 选一条已出结论作对照点，差额区出现服务端算好的青品差额。
6. printer 签发快照后再投新笔，打开该快照，点集仍是签发时那一版。
7. checker 能看轨迹与快照，但没有签发按钮（直接调接口也会被拒）。
